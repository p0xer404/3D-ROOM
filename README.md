# 3D-ROOM
This is a small project I have made where you can visualize 3D scans of your room. I made it because I didn't normally remembered where things in my room were, so this way I can see it.


It just two basic html files, nothing new, I will try to make it better, but for the moment that is just fine with me.
You can just execute them on your browser or use them in other more complex projects, do whatever you want, if you are in Github I'm sure you will figure out how to execute an html file.
